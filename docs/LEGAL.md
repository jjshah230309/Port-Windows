# Legal notes

* **Nothing copyrighted is bundled:** no games, BIOS images, keys, or Apple's Game Porting Toolkit. The firmware manager stores file *hashes* only, to recognise good dumps.
* **You supply your own** cartridge dumps, disc images and BIOS files, from media and consoles you own. Windows games come from your own Steam, GOG or Epic accounts.
* **Wine, DXVK and MoltenVK** are downloaded at runtime and run as separate programs; they are never linked into Attic.
* **D3DMetal (Apple GPTK)** is imported by you from Apple's own download, never redistributed by this project. Check Apple's license terms.
* **No DRM circumvention.** Games that depend on kernel-level anti-cheat or kernel-driver DRM are unsupported.
* **Neutral branding:** no console or company trademarks or logos in the app name, icon or UI. "Attic" is a placeholder; run a trademark search before release.
* **Clean-room implementation:** the emulator cores are written from public hardware documentation and test suites. Code from GPL or non-commercial emulators is not copied.

This is not legal advice.
